Battlevive Bot synchronizes Battlevive player, lobby, season-rating, and leaderboard data with Discord.

It can manage player and rank roles, generate rank cards, publish leaderboard images, and maintain live lobby posts with draft and result information.

## Important limitation

When trustworthy upstream Discord IDs are unavailable, the bot may link a Battlevive user through an unambiguous username or display-name match. This fallback is not identity verification. Use it only in trusted or testing communities until the upstream API provides trustworthy Discord identity data.
