Bot displays leaderbord of all users in the servers as and image. It can be configured by server staff. Bot needs correct permisions in the channel to work. It refreshes automaticly every 30s

# Configuration
Leaderbord channel can be configured using `/config leaderboard channel` by users with `manage_guild` permisions.
Max entries In the leaderboard can be configured by `/config leaderboard limit` It requires the same permisions.

## Warning
Unset/change leaderbord channel config when deleating leaderbord channel. 
Bot will try to send messages to this channel untill you deleate it.
Just type this and don't provide any value or new leaderbord channel 
``` /config leaderboard channel```
